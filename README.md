# Zyvest Capital Help Center

A standalone responsive help center built with HTML, CSS, and vanilla JavaScript.

## Open it

Open `index.html` in a modern browser. No build step or package installation is required.

## What’s included

- Responsive help-center landing page inspired by the reference documentation layout
- Six topic collections with 24 searchable guides
- Category filters, popular searches, keyboard shortcut (`Ctrl/Cmd + K`), article detail dialogs, mobile navigation, and light/dark theme toggle
- General trading and account education content, with account-specific requirements deferred to the authenticated client portal

## Content note

The supplied ThinkForge URL displayed a Zyvest Capital sign-in screen during review. It did not expose public product terms or account workflows, so this prototype avoids asserting account-specific eligibility, funding methods, fees, processing times, or support contact details.
